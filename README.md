GitHub User Explorer (Full-Stack Assignment) 🚀
Built a full-stack app using Node.js, Express.js, SQLite3 (🛠️) and React with Hooks (⚛️) to explore GitHub user data.

Backend 🔧

Fetches and stores GitHub user data via public APIs 📡

Detects mutual followers and marks them as "friends" 🤝

Supports search 🔍, soft delete 🗑️, field updates 📝, and sorting 🔢

Prevents redundant API calls and includes validation ✅

Frontend 💻

GitHub username input with user info and repository list display 📋

Detailed repository view 📄 and followers page 👥

Enables navigation between user profiles 🔁

Efficient data caching to reduce API calls ♻️

STEPS TO RUN PROJECT:

1. CLONE PROJECT IN LOCAL DIRECTORY
2. OPEN VS TERMINAL
3. RUN COMMAND "npm install"
4. GO INSIDE FRONTEND DIRECTORY
5. RUN COMMAND "npm install"
6. GO TO THE backend/ where server.js/ FILE IS PRESENT AND RUN COMMAND "node ./server.js"
7. GO TO THE frontend/ where app.js/ FILE IS PRESENT AND RUN COMMAND "npm start"
8. THAT's IT NOW AUTOMATICALLY PROJECT WILL RUN ON BROWSER.

 
NOTE: YOU SHOULD HAVE sqlite3 DOWNLOADED IN YOUR PC.
